Google Drive Auto-Save

When ON, every customer you save is also sent to your Google Drive, in the folder SK PAN CENTER → customer name (details, photo, signature, PDF). Needs internet and a one-time setup (Apps Script). Works when this file is opened in Chrome (not in the online link).

Backup / Restore

Your records may contain personal details. Keep the backup file safe and do not share it with others.

Taking a backup downloads customer details, attached PDF files, photos and signatures as a JSON file. Restoring adds the records to the current records; a record with the same ID is replaced.
